# Editable Foid Rive source

This Rive CLI project contains `scene.rml` and its referenced character artwork. Run the official Rive CLI in this directory to validate and compile it. `rive.yaml` names the resulting binary `build/foid.riv`. The website and CLI package use the compiled v0.0.1 file in the root `assets/` directory. Preserve the original artwork and authoring source when editing.
